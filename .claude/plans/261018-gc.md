# gc : dead tasks leak in parent dns

# Goal

- dead tasks must leave parent `_.dns`
- issue: lua-atmos/atmos#23
- origin: upstream commit `8023029` (pgvalle-research)
    - flags parent gc in `meta_par.__close`
    - fixes `par_any` / `watching` only

# Root cause

- gc flag set ad hoc at 2 of 3 death sites
    - normal end: `task_result` (`run.lua:128`)
    - abort: `M.abort` (`run.lua:435-437`)
    - close/error exit: missing
- error exit skips subtree close (`run.lua:121-123`)
    - children of errored task stay alive
    - their defers run only at `stop`
- `task_gc` only removes `meta_xtask` (not pools)
    - `atmos/run.lua:140-149`
- `pairs(ts)` drops 4th (close) value (lua 5.4)
    - `ing` stuck at 1, pool never swept again
    - `atmos/run.lua:16-33`
- emitter aborted mid-traversal never resumes
    - `emit` `ing` stuck > 0, root never swept again
    - e.g. nested `emit_in("global")` + parent ends

# General fix (prototyped in scratch)

- rule: whoever kills a task flags its parent
    - single site: `meta_xtask.__close`
- [x] `meta_xtask.__close`: flag `t._.up._.gc` (+3)
- [x] `task_result` error exit: call `__close` (+1)
    - closes subtree, runs child defers now
- [x] remove flag in `M.abort` (-3)
- [x] remove flag in `task_result` normal end
    - `__close` at its end already flags parent
    - sweep only at end of outermost reaction
- net: +4 / -3 lines
- covers: `par_any`, `watching`, `await or/not`
- covers: `catch`/`pcall` + `spawn`/`emit` throw
- covers: `abort(pool)` children
- drops upstream `8023029` (not needed)
    - PR lua-atmos/atmos#22 (pgvalle)
- rejected: one-liner flag at `run.lua:122`
    - would orphan children of errored task
    - their defers would never run

# Other fixes

- [x] `stop`: `task_gc(TASKS)` after close (+1)
    - verified: root kept dead tasks
- [x] `__pairs`: inline `ipairs(ts._.dns)`
    - no copy, no `ing`, no `max`, no state table
    - visits tasks spawned during the loop
    - `await`/`emit` in body may skip tasks
    - documented: `guide.md` 5.2, `api.md` `tasks`

# Remove `ing` (deferred sweep)

- [x] `GC[up] = true`: global set of parents
    - set dedups: no `gc_mark`, no `gc` field
    - set only by `meta_xtask.__close`
- [x] `M.gc()` (`atmos.gc`): replaces `task_gc`
    - called between reactions only (no traversal)
    - `loop`: after each `env.step()`
    - `stop`: after closing all tasks
    - `start` envs (e.g. JS): after each callback
        - documented in `atmos/env/README.md`
    - rejected: `DEPTH` + `<close>` in `emit`/`spawn`
        - more machinery in core, every call
    - rejected: "outside any task" check
        - scheduler runs nested in main thread
- top-level `emit` without env: never swept
    - tests/scripts must call `atmos.gc()`
- [x] drop `ing` from `emit`, `task_gc`, 3 fields
- [x] `GC` is plain hash table (not weak)
- dead child stays until next `atmos.gc()`
    - may break `#ts` checks in tests without `loop`

# Aborted tasks: termination emit

- `task_result` edit (user): aborted-while-running
    - no longer emits own termination
    - consistent with aborted-while-suspended
    - but `await(t)` on aborted `t` wakes late
        - only on next unrelated event
- [x] B: emit termination in `meta_xtask.__close`
    - `task_ended(t)`: single emit site (forward local)
    - no `quiet`: every close emits (decision)
        - cascade, task error, `stop`, toggle gate, unwind
        - children emit one by one, parent emits last
        - later siblings may awake (like `abort(ts)`)
    - `t._.ended`: emit at most once
    - aborted while running: emits on deferred close
    - `task_result`: dead -> `t.ret` + `__close`
    - order change: children closed before waiters wake
    - open: error raised by waiter inside `__close`
    - `abort(ts)`: tasks aborted in order, each emits
        - later task may awake on previous termination
        - by design (deterministic, like normal ends)
        - documented: `api.md` `abort`
- alternatives (not chosen)
    - A: revert edit (inconsistent, as before)
    - C: queue aborted terminations to end of reaction
    - D: document late wake

# Simplify close / task_result

- [x] inline `task_ended` in `meta_xtask.__close`
    - forward `TASKS`, `_me_` instead
- [x] `status`: `nil|toggled|aborted|ended` (no `ended` field)
    - `ended`: early return (closed again: dead in `dns`, abort)
- [x] `__close` closes `suspended` and `dead` coroutines
    - dead: runs pending `<close>` of errored coroutine
    - running/normal: mark `aborted`, closed in `task_result`
- [x] `task_result`: dead -> `ret`; dead/aborted -> `__close`
    - no `coroutine.close` there anymore
- order change: on error, children defers before task's
- [x] `toggle`: no-op on `ended` task
    - status kept: no re-close / re-emit
- [x] `__close`: re-raise defer error on abort
    - was `assert(ok or dead)`: lost error object
    - raised after `ended` / `GC`
- [x] `M.emit`: abort yield only for user emits (`stk`)
    - termination emit yielded inside `__close` cascade
    - froze close halfway (streams "par 3")
- [x] `M.emit`: abort yield only for user emits (`stk`)
    - termination emit yielded inside `__close` cascade
    - froze close halfway (streams "par 3")
- [x] dying subtree is inert
    - `emit` skips `aborted` subtrees (not only resume)
    - pool `__close`: temp `aborted`, restores status
    - fixes sibling wake on `stop` / `abort(ts)`
        - e.g. `tasks.lua` "toggle 1" printed at `stop`
    - reverts "later sibling may awake" (by design)
- [x] `__close` marks `aborted` before closing children
    - `emit` never resumes `aborted` (normal + `atm_error`)
    - bug: dying parent awoke on its child's termination
        - e.g. `await(y)` + `stop` printed after await

# Toggle gate

- `t._.toggle.task`: hidden off-tree gate (always xtask)
- [x] `meta_tasks.__close`: also close pool gate
- [x] gate `pass`: flag reset by `emit`, not `M.TIME`
    - abort termination (nested emit) bumped `M.TIME`
    - open: transparent abort emits (visible to `await(true)`)
    - was left suspended for toggled-off pools

# Status

- env-driven `atmos.gc()` applied
- all suites pass (`gc.lua` still out of `all.lua`)
- blocked: `await not 1` (stranded `par_any` trap)
    - see `261019-par-any.md`
- open: `loop` does not sweep before first `step`
    - tasks dead in body's initial run survive 1 step

# Verified leaks (scratch runs)

- `par_any` / `watching` loop: 1 task per iteration
- `catch` + `spawn` throw loop: 1 per iteration
- `catch` + `emit` throw loop: 1 per iteration
- `abort(pool)`: pool keeps dead children
- `tasks()` in loop: pools never removed
- errored task: children/defers alive until `stop`

# Not leaks

- `toggle` block loop: bounded
- `abort(t)` loop: bounded

# Won't do (suggested)

- unclosed `tasks()` in loop
    - by design: pool lives with its task
- pool `<close>` / `abort(ts)` in loop
    - by design: closed pool still usable
    - stays in parent `dns`
- sweep by `up`+`idx`, or single compaction pass
    - `table.remove` shift is O(n) anyway
    - swap-remove breaks lexical order
