# Goal

- First-class timers as in Céu (TECS'17, sec. 2.5)
- residual delta (`late`) carried across timers
- timers expire in time order within one tick
- paper figs 11 and 12 behave as in Céu
- issue: lua-atmos/atmos#25

# Céu model (`src/c/ceu.c`, `ceu_wclock_`)

- globals: `late`, `min_set`, `min_cmp`
- `await N` (set):
    - `t = N - late`
    - `min_set = min(min_set, t)`
- broadcast `WCLOCK(dt)`:
    - `min_cmp = min_set`, then `min_set = INF`
    - if `min_cmp <= dt`: `late = dt - min_cmp`
- each awaiting timer (sub):
    - expires iff `t <= min_cmp` and `t <= dt`
    - else `t -= dt`, then update `min_set`
- residual: re-emit `WCLOCK(0)` while `min_set <= 0`
- `await N` returns `late`
- external non-clock input resets `late = 0`

# Atmos today (`atmos/run.lua`, `M.await`)

- `await(us)`: local `clk` counts down on numeric emits
- wake returns overshoot `-clk`
- gaps:
    - no carry: next `await(us)` restarts from full `us`
    - one tick wakes all expired timers in tree order
    - fig 11.b ends with `v=2` (Céu: `v=1`)
    - `clk <= 0` returns at once (bypasses ordering)

# Design: split tick into public pieces

- idea: `emit(dt)` = `emit(d1)`, `emit(d2)`, ... with `sum = dt`
- each piece ends at the next timer expiry
    - woken timer is exactly on time
    - new `await(us)` starts from that instant
    - carry is implicit (no `us - late`, no `emit(0)`)
- equivalent to Céu (fig 12.a: `await(late + us)` = real now)
- clock state in `run.lua`:
    - `CLK = { min=INF, late=0 }`
    - save/restore around nested numeric emits
- loop in `M.emit` when `emt` is a number:
    - `rest = dt`
    - `d = min(CLK.min, rest)`
    - reset `CLK.min = INF` only if target `== TASKS` (7)
    - `CLK.late = rest - d`
    - broadcast `d` (plain number, public)
    - `rest -= d`, repeat while `rest > 0`
    - end: `CLK.late = 0`
- `M.await(us)`:
    - on set: report `clk` to `CLK.min`
    - on number `d`: `clk -= d`
    - `clk <= 0`: wake, return `CLK.late`
    - else: report `clk` to `CLK.min`
- stale `CLK.min` (aborted timer): one empty split, harmless
- `'clock'`, `true`, functions see each piece
- `await('clock')` returns `d, CLK.late` (6)
- `toggle(t, true)` sends `emit(0, t)` (4)
- split `clk` and `'clock'` branches in `M.await`

# Decisions

1. Public pieces (decided)
    - `'clock'` / `true` wake once per piece
    - deltas still add up to `dt`
2. `await(us <= 0)`: return at once, as today (decided)
    - returns `CLK.late - us` (outside tick: `-us`, as today)
    - never reports to `CLK.min`, so pieces stay `> 0`
3. `await(0)` loop never yields: *won't do* (as today)
    - no assert: `await(late + x) <= 0` stays valid
4. Toggle on: `emit(0, t)` inside `toggle(t, true)` (decided)
    - resumed timers re-report to `CLK.min`
    - plain `0`: `'clock'` / `true` in `t` also wake
    - requires 7: targeted piece keeps `CLK.min`
5. Fig 12.b: huge `dt` with tiny timer = many pieces
    - intended catch-up (decided: document only)
    - cost: pieces x tasks per tick
    - doc fig 12.b pattern: check `late`
    - cap on pieces: *won't do*
6. Frame code on `'clock'` runs per piece (decided)
    - `await('clock')` returns `d, CLK.late` (additive)
    - `late == 0`: last piece, real tick done
    - doc: draw on env draw event or on `late == 0`
    - whole-tick `'clock'`: *won't do*
7. Targeted ticks: reset `CLK.min` only if target `== TASKS`
    - (decided)
    - targeted / `emit(0, t)`: keep min (lower bound)
    - stale min: extra empty pieces until next global
    - note: default `emit` target is current task (`fto`)

# Environments

- new `atmos.next()`: us to nearest timer
    - `CLK.min`, `nil` if `INF`
    - relative to last delivered tick
    - lower bound: early wake = empty tick, harmless
    - OS jitter: absorbed by `late`
- env loop sleeps until `next()` or external input
    - `nil`: block on input only
    - read again after each step (emits change it)
- emit elapsed tick before each external input
    - as Céu `ceu_input` (wclock first)
    - else timers born on input expire early
- `socket`:
    - `select` timeout = `next()` (not fixed 0.1s)
    - move tick emit before recv/send emits
- `iup`:
    - one-shot timer at `next()` (not fixed 100ms)
    - emit real elapsed, not fixed `100*1000`
- `pico` (and external `env-sdl`):
    - frame-driven: keep fps ticks
    - optional: event timeout `min(frame, next())`
- `clock`:
    - busy loop on `os.clock` (CPU time)
    - sleep stops CPU time: needs wall clock
    - suggest *won't do* (keep busy loop)
- secondary mode: never sleeps (as today)
