# gc : dead tasks leak in parent dns (fresh)

# Goal

- dead tasks leave parent `_.dns` on every exit path
- simplest fix, one step at a time
- issue: lua-atmos/atmos#23
- prior attempt: branch `v0.9-todo` (`b6d8e51`)

# Leaks (verified in prior attempt)

- `par_any` / `watching` / `await or/not`: 1 per iteration
- `catch` + `spawn` / `emit` throw: 1 per iteration
- `abort(pool)`: pool keeps dead children
- errored task: children/defers alive until `stop`
- `pairs(ts)`: `ing` stuck at 1 (4th value dropped)
- aborted emitter: `ing` stuck > 0, never swept again
- `stop`: root keeps dead tasks

# Root cause (`atmos/run.lua`)

- parent gc flag set at 2 of 3 death sites
    - normal end: `task_result` (`run.lua:128`)
    - abort: `M.abort` (`run.lua:436`)
    - close / error exit: missing
- `task_gc` sweeps only when `ing == 0`

# Lessons (prior attempt)

- keep termination semantics as is
    - emit on every close broke: `par_any` trap, toggle gate,
      sibling wake on `stop`, yield inside `__close`
- `atmos.gc()` env-driven sweep: big API change
    - `tst/gc.lua` `emits()` still calls it

# Regression (found by atmos-lang abort 27, 30, 32)

- since `b120a07`: aborted end emits nothing
    - emit used to stop parent aborted by spawned child
    - now parent keeps running after `spawn` returns
- [x] `M.spawn`: after `task_result`, yield if `me` aborted
    - shared `yield_if_aborted`: `M.abort`, `M.spawn`, `emit_`
    - all suites pass
- emitter aborted by awakened task: emit now completes
    - outer tasks still awake (was: emitter yielded mid-broadcast)
- `<close>` block: child's defer aborts ancestor: crash (pre-existing)
